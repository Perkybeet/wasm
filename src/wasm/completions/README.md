# Shell completion

These are generated by Click and committed, not built.

They contain no command names. Each one is a fixed shim that calls back into
`wasm` when the operator presses tab, so the completions cannot drift from the
command tree the way the previous hand-written 2,295 lines did, and there is
nothing to regenerate when a command is added.

Committing them removes the need to run Python during the distribution package
build. Doing that is what made every OBS target fail: generating them required
the package to be importable, so every runtime import became a build
dependency, on every distribution, on every architecture.

Regenerate with `scripts/generate_completions.py` after upgrading Click.
`scripts/generate_completions.py --check` runs in CI.
