# WASM 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Jinja/htmx panel with a React SPA ("WASM Console") over a complete, uniform JSON API, add an atomic-release deploy engine with instant rollback, real domain management, sudo mode and full CLI/panel parity, and ship it as v2.0.0.

**Architecture:** The Python package keeps the managers/deployers core (refactored, not rewritten). `src/wasm/web` becomes API-only (FastAPI + SSE + two WebSockets) and serves a prebuilt SPA whose source lives in `panel/` and whose Vite build is committed to `src/wasm/web/static/`. The deploy engine gains a `releases/ + current + shared/` layout managed by one `ReleaseManager`.

**Tech Stack:** Python 3.10+, FastAPI, pydantic v1/v2 via `wasm.web.pydantic_compat`, SQLite; React 19, TypeScript (strict), Vite, TanStack Router + Query, Tailwind CSS v4, Base UI (`@base-ui/react`), lucide-react, uPlot, Vitest, Testing Library, axe-core, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-25-wasm-v2-design.md` (read it before any task; decisions D1-D11 are referenced below by number).

## Global Constraints

- The four rules in `CLAUDE.md` apply to every task: processes only through `CommandRunner` (argv, timeouts, secrets via env/stdin); broad `except` only at error boundaries and logged; one implementation of each thing; guards at the chokepoint.
- Python: type hints everywhere, modern syntax (`X | None`), Google-style docstrings with Args/Returns/Raises on everything public, comments explain why. No emojis anywhere.
- Every new pydantic model or validator goes through `src/wasm/web/pydantic_compat.py` (Ubuntu 24.04 ships pydantic 1.10; `tests/test_architecture.py::TestPydanticBridge` enforces it).
- No new Python runtime dependency. Frontend dependencies are build-time only; nothing but the committed build ships.
- OBS builds from `git archive HEAD` with no network: `src/wasm/web/static/` (the Vite build) must be committed; Node never runs during packaging.
- CSP for the console: `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'self'; frame-ancestors 'none'; base-uri 'none'; form-action 'self'; object-src 'none'`. No inline scripts, no inline `<style>` elements.
- Node version: the major in `panel/.nvmrc` (22) is the one CI uses; `package-lock.json` is committed and `npm ci` is the only install command in CI.
- UI copy is English (international product), sentence case, no exclamation marks, errors show the system's own output verbatim in mono with the suggested fix above it.
- Colour encodes state only (running green, in progress amber, failed red, stopped grey) plus the violet accent for interactive elements; every status also has a shape and a text label.
- WCAG 2.2 AA: axe must report zero violations on every page in both themes; the E2E fails otherwise.
- Tests never touch the real machine: `tests/conftest.py` blocks subprocess and sockets; use `FakeRunner`, `DryRunFileSystem`/`RecordingFileSystem`, the store sandbox.
- Commits: conventional prefix (`feat(api):`, `fix(core):`, `feat(console):` ...), no AI references, no Co-Authored-By.
- Work happens on branch `refactor/v2`; `main` stays releasable at v1.6.x until the final merge.

## Review Focus

- A panel restart in the middle of a deploy: the job must reappear as failed ("interrupted by a panel restart") in history, never vanish or stay "running" forever. Task 1.7 pins it.
- A session that expires while the console is open: the next request must land on the login page with a "session expired" notice and return to the same URL after login, not show a blank page or a raw 401. Task 2.4 pins it.
- An app deployed by v1.x (in-place layout) being updated by v2: it must keep updating in place, untouched, until explicitly migrated; the release engine must never be applied to it implicitly. Task 4.2 pins it.
- A migration of an app whose tree holds user uploads not tracked by git: the uploads must end in `shared/` and stay served; nothing may be deleted. Task 4.3 pins it.
- The operator pasting a `.env` with comments, quoted values, `export` prefixes and CRLF line endings into the bulk editor: it must parse exactly like `EnvManager` parses files. Task 3.7 pins it.

```python
    """The panel and the CLI write at once; the default journal fails the second writer."""

def test_concurrent_first_use_initialises_once(tmp_path: Path, monkeypatch) -> None:
    """Two threads calling get_store() first must not both run the migrations."""
    import threading
    WASMStore.reset_instance()
    calls = []
    original = WASMStore._ensure_schema
    def counting(self):
        calls.append(1)
        return original(self)
    monkeypatch.setattr(WASMStore, "_ensure_schema", counting)
    barrier = threading.Barrier(8)
    def worker():
        barrier.wait()
        WASMStore(tmp_path / "wasm.db")
    threads = [threading.Thread(target=worker) for _ in range(8)]
    for t in threads: t.start()
    for t in threads: t.join()
    assert len(calls) == 1
    WASMStore.reset_instance()
```
